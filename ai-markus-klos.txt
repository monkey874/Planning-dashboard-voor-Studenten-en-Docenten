Q: i want to hide the qr code + have have a buttton "use phone" that when clicked shows the qr code like currently

A: Updated resources/views/subscription.blade.php. Each of the three calendar
options (Apple, Google, Outlook) now wraps its <x-qr-code> in a native HTML
<details>/<summary> element. The <summary> is styled as a button labeled
"Use phone" and is collapsed by default, so the QR code is hidden on page
load. Clicking the button toggles the <details> element open, which reveals
the QR code below it. No JavaScript was needed since <details>/<summary> is
a built-in browser disclosure widget; Tailwind classes were used to style
the summary as a button (border, padding, hover background) and to
center/size the QR code once shown.
